# OSINT
advanced digital forensics project
1)usersearch
the scripts uses the APIs of github, twitter and reddit to search for users by username ,we enter the username and the script shows the output whether it is found or not and shows the error reason if there's any
2)reddit 
the sctipt shows the information of a reddit profile using the usernames that we can confirm using the first script and it shows : the usernmame,date of creation, karma and the icon of the profile
3)instagram scraper
this script uses selenium to go to the targets instagram profile and get the profile data (username , following, followers, post count, and gets us the links of the posts)
